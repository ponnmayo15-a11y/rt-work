# rt-work

診療放射線技師の仕事まわり（CT認定更新、技師会・研究会の情報）

## CT認定技師 単位講習会リサーチ

X線CT認定技師の更新（5年で30単位）に使える講習会を毎週自動でリサーチし、
Googleスプレッドシートにリスト化する仕組みです。

### 仕組みの概要

1. 日本X線CT専門技師認定機構の「[単位認定講習会等一覧](https://www.ct-ninteikikou.jp/nintei/tani_nintei_list/)」
   （単位対象と認められた講習会だけが載る公式リスト）を毎週チェックし、前回チェック以降に
   新しく追加された回・まだ開催日を迎えていない回だけを対象にする。
2. 各回の詳細PDF（チラシ）を取得し、開催形式（オンライン/オフライン）・開催都道府県・参加費を
   自動で読み取る。
3. 以下の条件で判定する。
   - タイトルに「学術大会」「学術集会」「臨床大会」「総会」「全国大会」を含む
     → 技師会・技術学会の大きな学会とみなし、他の条件を問わず採用
   - オンライン開催 かつ 参加費1000円以内 → 採用
   - オフライン開催 かつ 山梨・東京・静岡・神奈川・長野のいずれか かつ
     休日開催（山梨県内のみ平日18時以降開催も可）→ 採用
   - 上記以外で、開催形式・開催地・参加費のいずれかが自動判定できなかったもの → 「要確認」として別タブに掲載（見落とし防止のため、対象外と決めつけず人の目でのチェックに回す）
4. 採用/要確認の講習会をGoogleスプレッドシートに追記する。

### 出力先スプレッドシート

https://docs.google.com/spreadsheets/d/1lDodnyDqkZkGyNy8l2OUpxeg1r0muHpdSCme2hiak_k/edit

3つのタブがあります。

- **対象講習会リスト**: 条件に合致した講習会
- **要確認**: 自動判定できず人の目でのチェックが必要な講習会（詳細PDFが無い/取得失敗、
  参加費や開催地が読み取れない、開催地の判定確度が低い、など）
- **実行ログ**: 実行日時・新規確認件数・追加件数などの記録

### 自動実行（週次）

`.github/workflows/weekly_ct_credit_research.yml` により、毎週月曜8:00 JSTに自動実行されます。
GitHub Actionsの `Actions` タブから手動実行（workflow_dispatch）も可能です。

**重要**: GitHub Actionsのスケジュール実行はデフォルトブランチ（`main`）にあるワークフローだけが
対象になります。このブランチが `main` にマージされるまでは、週次の自動実行は始まりません。

#### 事前準備: GitHub Secretsの設定

リポジトリの `Settings > Secrets and variables > Actions` で以下の3つを登録してください
（値は okfka240n@gmail.com のOAuthクライアント情報・リフレッシュトークン）。

- `GOOGLE_CLIENT_ID`
- `GOOGLE_CLIENT_SECRET`
- `GOOGLE_REFRESH_TOKEN`

### 手動実行

```bash
pip install -r requirements.txt
export GOOGLE_CLIENT_ID=...
export GOOGLE_CLIENT_SECRET=...
export GOOGLE_REFRESH_TOKEN=...
python -m ct_credit_research.main
```

### 設定のカスタマイズ

`config/settings.yaml` を編集するだけで挙動を調整できます。

- `online_fee_max_yen`: オンライン講習の参加費上限（円）
- `allowed_offline_prefectures` / `home_prefecture` / `home_weekday_evening_start`:
  オフライン講習を許可する都道府県・平日夜も可とする地元県・その開始時刻
- `major_conference_keywords`: 無条件で採用するタイトルキーワード
- `prefecture_keywords`: 都道府県判定に使うキーワード（市区町村名など）
- `online_keywords` / `free_keywords`: オンライン判定・無料判定に使うキーワード

### 状態管理

`data/state.json` に、処理済みの認定No.一覧とスプレッドシートIDを保持しています。
GitHub Actions実行後、このファイルは自動でコミット・プッシュされます
（手動でファイルを編集する必要は基本的にありません）。

### 既知の制約

- 開催地・参加費はチラシPDFの全文からキーワードで自動推定しています。デザイン重視のチラシは
  テキスト抽出順序がレイアウト通りにならないことがあり、講師の所属病院名などから誤って地名を
  拾ってしまう可能性があります。「対象講習会リスト」に載った回でも、特に開催地については
  リンク先のPDFで一度確認することをおすすめします。
- 参加費は「会員/非会員」など複数の金額が書かれている場合、自動判定では最も安い金額を採用します。
  「検出した参加費」列に検出できた金額をすべて表示しているので、該当しない場合は参加費列を確認してください。
- 「単位認定講習会等一覧」に開催日の記載ミスなど、サイト側のデータに不備がある回は日付が
  正しく読み取れず「要確認」に回ることがあります。
